# Custom-Scientific-Calculator
An open-source custom scientific calculator based on an ESP32, featuring a dedicated keypad matrix, MCP23017 I/O expansion, ST7789 display, rechargeable Li-ion power system, and a custom PCB.

# Project Status
## Work-In-Progress (WIP)
The hardware is currently undergoing PCB and mechanical development. Firmware and enclosure designs are also under active development and may change as physical prototypes are assembled and tested.

# Features
- ESP32-based controller
- ST7789 Color TFT (2.8 inch)
- MCP23017 I/O Expander
- 45 key Physical key matrix (custom)
- SD card support(OPTIONAL)
- Scientific and mathematical functions
- Rechargeable battery
- Mdular/Serviceable design (planned to make a compact version, consisting of SMTs instead of THTs)
- Custom PCB
- Custom enclosure

# Repository Contents
HARDWARE/ - Schematic, BOM, and PCB layout
FIRMWARE/ - Sketch Code and other software related contents
CAD/ENCLOSURE/ - Enclosure and Mechanical CAD files
Manufacturing/ - fabrication-ready manufacturing files

# Hardware
The calculator uses a custom PCB designed specifically for the project. The hardware is still being refined and has not yet completed final physical validation.

# Firmware
Firmware development is currently in progress. The included firmware represents the current development state and is subject to change as the hardware is validated.

# CAD
The enclosure and other mechanical components are included as CAD files. These designs are still being refined alongside the PCB and physical prototype.


# Goals
The goal is to create a functional, portable scientific calculator while gaining practical experience in:
- PCB design
- Embedded programmng
- Human-machine interfaces
- Power management
- Mechanical design
- Electronics Manufucturing
